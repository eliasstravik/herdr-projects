== the ? menu
 Menu  for #5 "Max length for task titles"
 plain keys
   ↑ ↓          move between tasks and headings
   ← →          fold the heading; on a task's row, go to its heading
   pgup pgdn    a page of tasks up or down (in the whole task: a page of its text)
   tab          the next filter on top: all, coordinators, needs you, working, ready, to do, done, automations
   enter        send what is typed; else fold or unfold a heading
   space        talk to this row's agent, and back to the top row's coordinator
   esc          back, one step at a time (as a popup, the board closes on the last one)
   ?            this menu
   y  n         answer a question: y yes, n or esc no (enter never confirms)
   /            typed first: pick a skill of whom you talk to

 ctrl: does something
   ctrl+l       yes: approve the merge, say yes, retry, take it as it is
   ctrl+r       send it back: tell the agent to fix it, or to continue
   ctrl+s       put an agent on this task
   ctrl+x       stop this task's agent
   ctrl+a       archive this task
   ctrl+p       pin this task to the top
   ctrl+e       this task's settings: see and change each one
                your own settings: what every task starts from
   ctrl+z       undo
   ctrl+f       find: show only the tasks that match
   ctrl+c       twice: close the board
   ctrl+t       a voice call with whoever the chat talks to

 alt: only shows or hides
   alt+c        hide the chat's latest message
   alt+k        scroll the chat's message up
   alt+j        scroll the chat's message down
   alt+p        show the side panel: this task, beside the list
   alt+t        show the whole task, full screen
   alt+a        show the archive
   alt+s        group by repo: see which repo each task is in
   alt+d        show all done
   alt+m        look for other machines (now: this machine)

 on a row
   ◐            an agent works
   ◑            its reviewer works
   ◇            the board's own step (it checks, waits for GitHub, merges)
   ◌            queued: for a free slot (Q#1 next) or after other tasks
